# Contributing to SnapScroll

Thanks for your interest in improving SnapScroll.

## Before submitting a change

- Test the extension in Microsoft Edge.
- Keep the extension focused on full-page webpage capture.
- Avoid adding permissions unless they are necessary.
- Do not introduce remotely hosted executable code.
- Test both normal documents and pages with nested scroll containers.
- Update the README when user-visible behavior changes.

## Pull requests

Please describe:

- what changed;
- why it was needed;
- how you tested it;
- any known limitations.

For capture-engine changes, include the types of pages you tested when possible.

## Bug reports

Use the GitHub issue tracker and include the Edge version, SnapScroll version, affected website, export format, and a clear description of the problem.

Do not upload private screenshots or captured pages containing sensitive information.
