# Security Policy

## Reporting a vulnerability

Please do not publicly disclose security-sensitive issues before they have been reviewed.

Open a private security report through GitHub if the repository supports private vulnerability reporting. Otherwise, contact the maintainer through the GitHub profile:

https://github.com/dev-maegor

When reporting an issue, include a clear description, affected component, reproduction steps, and potential impact. Do not include passwords, tokens, personal data, or other secrets.
